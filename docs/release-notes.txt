aside tweaks 4.21.0 – 2026-09-16

- ⌘D follows Arc: the bookmark joins the end of the bar, the rows above keep their places, the tab stays open and selected, and a second ⌘D takes the row out; closing the tab after ⌘D became a setting and is off by default
- ⇧⌘D keeps the focus on the tab after pinning and unpinning
- fixed duplicate cleanup: the function had lost every caller, so no key and no surface could reach it. cleanup now runs from the review confirmation, covers every window and writes a receipt
- the popup tile and review show the same number, the one the confirmation will actually close
- a bookmarked page no longer protects each of its own copies inside an exact-duplicate cluster
- review opens with the summary and the confirm line; a related cluster wider than 8 tabs offers no batch
- ⌘1…⌘9 switch to the blocks of the window, ⇧⌘1…⇧⌘9 put the current tab into a block, and the palette lists what each number holds
- added the Arc multi-select gesture: shift-click several tabs, then one command turns the selection into a named block; added fold and unfold for all blocks
- the ⌘K action panel is the same on every row type, notes carry the reason they are on the list, and rows without a favicon get a monospace letter avatar
