01 · three moves

A place for the page. A next step for you.

The extension changes the small transitions that make a crowded browser feel unpredictable. The installed settings expose these exact behaviors.

⌘D

keep the page first

The page becomes the first bookmark, its tab closes, and focus moves to the next unpinned tab. Press again on that page to return it to the top of Tabs.

⇧⌘K

search the whole desk

Tabs, history, bookmarks, Obsidian notes, Aside menu items, commands and configured agents share one field.

⌥⌘D

review before cleanup

Exact copies, related products, stale events and research sources stay separate until you choose what to keep, bookmark or close.

02 · cleanup contract

The browser keeps its memory.

Model grouping can propose names. It never applies them. Destructive actions stay behind a human preview and leave a local source receipt.

review / receipt

one canonical tab per product.

Name the working cluster, keep its product surface, bookmark the source and close only the eligible siblings.

03 · operator

Install once. Reload safely.

Aside Tweaks runs unpacked from the canonical repository. The optional desk bridge stays on loopback and only exposes configured notes, menus and agent launch points.

01
clone the canonical product
git clone https://github.com/aPoWall/aside-tweaks.git
02
load unpacked in Aside

Open chrome://extensions → Developer mode → Load unpacked → choose the repository.

03
optional local desk bridge
bridge/install.sh
curl -H 'X-Aside-Tweaks: desk' http://127.0.0.1:49321/health

Migration: v4.19 preserves keymaps, bookmarks, review state and bridge config. New ⌘D saves at row one and selects the next unpinned tab. Rollback: check out v4.18, press Reload on the extension card; no browser profile migration is required.
