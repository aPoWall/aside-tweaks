the keys your browser kept for itself

a hundred tabs, four copies of one app under one title, a bookmark dialog nobody asked for. aside tweaks takes the keyboard back, folds a kept page into the bookmarks bar instead of copying it, sees a duplicate by title and by address, and puts one palette – built like raycast – over tabs, history, bookmarks, obsidian notes and the agents running on the machine.

built for aside – a chromium browser with an agent in the sidebar. runs on any chromium 114+, manifest v3. every surface is drawn in the sidebar's own look: grey field, white pill, system font.

type, don't hunt

the shape is raycast's: a row is icon, title, subtitle and its type on the right; the footer names what ↵ will do to the selected row; ⌘K opens the actions for that row – switch, pin, bookmark ⇄ tab, close, copy url. esc clears the query first and closes only when it is empty.

an empty query shows the tabs you were in last, current one at the bottom. a page open twice carries ×2. history collapses by normalised url. ranking follows what you actually pick – frequency with a two-week decay. paste an address and it offers to open it plainly, in a named block, or pinned. arithmetic answers. and with the desk bridge, notes from obsidian and agents from orca sit in the same list.

02 · a pin is a bookmark plus a tab
02

park, don't pile

aside's sidebar shows the bookmarks bar above the tabs. ⌘D writes the page as the last row of that bar, closes the tab and returns you to the page you came from. the row stays: one click opens the page again, and while it is open the sidebar folds the tab into that row – live, asleep with 💤 when discarded. that is arc's pinned tab, built from a bookmark and a tab.

⌘D on an open page that already sits in the bar removes the bookmark; the tab stays. the last tab of a window is never closed. settings card 02 can keep the tab open instead – it then leaves its block and moves to the first row, and the sidebar folds it in.

tidy up

⌥⌘T is four operations in one gesture, in the order that survives: duplicates and empty tabs closed, groups flattened, loose tabs on top by recency, blocks rebuilt from three tabs or more. flattening comes before grouping – a grouped tab refuses to cross its group boundary.

a duplicate is the same address through http, www, a trailing slash and tracking params – and since v4.15 also the same site under the same title: four «aim visual» tabs with four query strings are one page to the eye, and «0 duplicates» on them was a lie. of the copies the one you used last stays. «new tab» and titles that only repeat the address never match.

04 · the keys, rebindable right here

take the key back

an extension is normally allowed four shortcuts, re-bindable only on the browser's own settings page. this one listens on the page in the capture phase – before the browser applies its accelerator – so any combination the page can see becomes yours.

bindings are stored by physical key code, so a non-latin keyboard layout doesn't quietly break them. click a row on the right and press a combination – the recorder is the same one that lives in the extension.

05 · the desk, from the palette

notes and agents

a browser extension cannot read a file or start a process. a small local server does it on its behalf: it reads each vault's own «recent files» list from obsidian, keeps a filename index for search, and opens a note through obsidian://. type > and the same list shows the terminals running in orca – ↵ switches to one; > followed by a prompt starts a new claude in a folder you configured.

it listens on 127.0.0.1 only and answers only to a header this extension sends – a web page cannot add it without a cors preflight the bridge refuses. it opens only files inside a configured vault and starts an agent only in a configured folder. standard-library python, one launchagent, off until you install it.

and from anywhere: a global key cannot reach an extension, but it can open a page. the bridge serves a signal page; a raycast script command or ⌥⌘K in hammerspoon opens it in aside, and the extension turns that tab into the palette on the page you came from – or on a grey field where no page exists. type the query into raycast and the palette opens with it.

what each gesture moves

⇧⌘Kpalettea layer over the page: no title bar, the page darkens behind it. where no page exists it opens as a window. ⇥ switches scope, esc clears then closes
⌘Kactionsinside the palette: the actions of the selected row. switch · pin · bookmark ⇄ tab · close · copy url for a tab; open · pinned · in a block · copy for anything with an address. the printed keys work without opening it: ⇧↵ ⌘⌫ ⌘B ⌘C
⌥⌘Kfrom anywherea system key (raycast script, hammerspoon) opens the bridge's signal page in aside; the extension turns it into the palette on the page you came from, or on a grey field where no page exists. the signal tab never stays
>agentsin the palette: the live terminals to switch to; with text after it, «run in ‹folder›» rows that start a new agent with that prompt. needs the desk bridge
⌘Dbookmark ⇄ tabthe page joins the bookmarks bar as its last row, the tab closes, focus returns to the page you came from; the bar row opens it again. on an open page already in the bar: the bookmark goes, the tab stays. card 02 can keep the tab open instead
≡aside's menuthe browser's whole menu bar – 165 items with their keys – searchable from the palette and run from it, like raycast's search menu items but inside the browser. read through hammerspoon in half a second; the commands scope shows the whole tree
⇧⌘Dpinthe squares on top of the sidebar. unpinning returns the page to the first row of the tabs and keeps it selected
⌥⌘Dclean duplicatesby address or by host + title, plus empty tabs; the copy you used last stays. in the palette ⇧↵ on the row shows what would close – each tab with its reason and the copy that stays – before anything closes; ⌘⌫ there closes one at a time
⌥⌘Ttidy upclean, flatten, order, rebuild blocks – reported once, not four times
⌃⇧Spanelthe last rows of the bookmarks bar, pinned tabs, the rest by blocks, commands – one list of commands feeds the panel, the palette and the popup

the layer above extensions

⌘T, ⌘W, ⌘N, ⌘Q belong to the system and no extension reaches them – the browser consumes them before a page exists. those keys are menu commands, and macOS re-binds any menu command per application. the repo ships that as a script, so the browser's own bookmark dialog stops sitting on ⌘D:

$ scripts/native-shortcuts.sh
  Bookmark This Tab…         → ⌃⌘B    frees ⌘D
  Bookmark All Tabs…         → ⌃⇧⌘B   frees ⇧⌘D
  Always Show Bookmarks Bar  → ⌥⇧⌘B   frees ⇧⌘B

menus build their key equivalents at launch, so it bites after the browser restarts. --reset puts the stock keys back.

install in two minutes

$ git clone https://github.com/aPoWall/aside-tweaks.git
$ bridge/install.sh          # optional · notes, agents, the palette from anywhere · ~/.config/aside-tweaks/desk.json

chrome://extensions → developer mode → load unpacked → pick the folder. everything stays on the machine: the extension talks to the browser's own tab, history and bookmark apis, and – if you install the bridge – to a server on 127.0.0.1 that only answers to it.

what it will not do

the browser's own sidebar is native chrome – an extension cannot repaint or restyle it, and the theme colour leaves it alone. what this draws is themable instead, and by default it borrows the sidebar's own values: palette, popup, settings, panel. no extension can take ⌘T ⌘W ⌘N ⌘Q, on any browser, including the ones that advertise custom shortcuts. the browser's own ✦ tidy is part of that ceiling: no menu command, no url scheme, zero elements for accessibility – so this ships its own sweep. and the bridge does nothing until you install it; without it the palette has no notes and > points you to the settings card.
