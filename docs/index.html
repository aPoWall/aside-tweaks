fifty tabs, a bookmark dialog nobody asked for, new tabs landing at the top of the list. aside tweaks takes the keyboard back, moves a kept page to the top of the bar instead of copying it, and puts one palette over tabs, history and bookmarks.

built for aside — a chromium browser with an agent in the sidebar. runs on any chromium 114+, manifest v3.

take the key back

an extension is normally allowed four shortcuts, re-bindable only on the browser's own settings page. this one listens on the page in the capture phase — before the browser applies its accelerator — so any combination the page can see becomes yours.

bindings are stored by physical key code, so a non-latin keyboard layout doesn't quietly break them. click a row on the right and press a combination — the recorder is the same one that lives in the extension.

type, don't hunt

with fifty tabs open, scanning a sidebar is slower than typing three letters. the palette searches open tabs, browser history and bookmarks at once, and tab narrows the scope.

history collapses by normalised url, so one site stops flooding the list. ranking follows what you actually pick — frequency with a two-week decay. paste an address and it offers to open it plainly, inside a named block, or already pinned. type arithmetic and it answers.

tidy up

⌥⌘T is four operations in one gesture, in the order that survives: duplicates and empty tabs closed, groups flattened, order aligned, blocks rebuilt. flattening comes first — a grouped tab refuses to cross its group boundary, and a sweep that starts by grouping trips over itself.

order by site, or by the order you opened them. blocks are yours: a name plus substrings, and everything unmatched falls back to its root domain.

04 · keys and limits

what each gesture moves

⌘Dbookmark ⇄ tabthe page lands as the last row of the bookmarks bar and the tab stays open and loaded — press it again and the bookmark goes, the tab returns to the very top
⇧⌘Dpinthe squares on top of the sidebar. unpinning returns the page to the first row of the tabs and keeps it selected, so nothing gets lost in the middle of the list
⌥⌘Ttidy upclean, flatten, order, rebuild blocks — reported once, not four times
⇧⌘Kpalettea layer over the page: no title bar, no traffic lights, the page darkens and blurs behind it. where no page exists it opens as a window
⌃⇧Spaneltop of the bookmarks bar, pinned tabs, the rest by blocks, commands

the layer above extensions

⌘T, ⌘W, ⌘N, ⌘Q belong to the system and no extension reaches them — the browser consumes them before a page exists. those keys are menu commands, and macOS re-binds any menu command per application. the repo ships that as a script, so the browser's own bookmark dialog stops sitting on ⌘D:

$ scripts/native-shortcuts.sh
  Bookmark This Tab…         → ⌃⌘B    frees ⌘D
  Bookmark All Tabs…         → ⌃⇧⌘B   frees ⇧⌘D
  Always Show Bookmarks Bar  → ⌥⇧⌘B   frees ⇧⌘B

menus build their key equivalents at launch, so it bites after the browser restarts. --reset puts the stock keys back.

install in two minutes

$ git clone https://github.com/aPoWall/aside-tweaks.git

chrome://extensions → developer mode → load unpacked → pick the folder. everything stays on the machine: the extension talks to the browser's own tab, history and bookmark apis and to nothing else.

what it will not do

the browser's own sidebar is native chrome — an extension cannot repaint or restyle it, and the theme colour leaves it alone. what this draws is themable instead: palette, popup, settings, panel. and no extension can take ⌘T ⌘W ⌘N ⌘Q, on any browser, including the ones that advertise custom shortcuts. the honest ceiling is written down rather than hidden. the browser's own ✦ tidy is part of that ceiling: no menu command, no url scheme, and the window reports zero elements to accessibility — so this ships its own sweep instead of pretending to press that button.
