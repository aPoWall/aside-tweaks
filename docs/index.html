01 · review model

Four states. Clear ownership.

The review surface separates certainty from context. Exact copies can form a batch. Related pages stay a product decision. Events and research keep their own lifecycle.

STATE 01

Exact duplicate

Same normalized address, or the same meaningful title on one site.

preview batch
STATE 02

Related product

Pages from one working thread across apps, local previews and source systems.

choose canonical
STATE 03

Stale / event

Time-bound pages remain visible as a separate review queue.

explicit close
STATE 04

Research source

References can be bookmarked and carried into the product handoff.

bookmark source
02 · safety contract

The browser keeps its memory.

Pinned, active, bookmarked, user-marked and unsaved-form tabs are protected. Model grouping stays a proposal. A destructive batch always receives one final preview.

Pinned

Top-level anchors keep their place.

Active

The page in hand cannot enter a close batch.

Marked

Canonical and user-protected pages persist.

Unsaved

Dirty forms report a boolean guard; field values stay private.

Receipt

Canonical page, sources and closed URLs are recorded locally.

04 · operator

Install once. Reload safely.

The unpacked extension runs directly from the canonical repository. The optional bridge is a separate LaunchAgent with a local health endpoint.

01
Clone the canonical source
git clone https://github.com/aPoWall/aside-tweaks.git
02
Load unpacked in Aside

Open chrome://extensions, enable Developer mode, choose Load unpacked, then select the repository.

03
Optional desk bridge
bridge/install.sh
curl -H 'X-Aside-Tweaks: desk' http://127.0.0.1:49321/health
Migration: v4.18 ignores the old auto-dedupe switch and opens review for cleanup shortcuts. Existing keymaps, bookmarks and bridge config remain.
Rollback: check out the previous tag or commit, then press Reload on the extension card. No browser profile migration is required.
