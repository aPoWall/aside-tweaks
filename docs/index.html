aside tweaks. the keys your browser kept for itself.

a hundred tabs, four copies of one app under one title, a bookmark dialog nobody asked for. aside tweaks takes the keyboard back, parks a kept page in the bookmarks bar, sees a duplicate by title and by address, and puts one palette – built like raycast – over tabs, history, bookmarks, obsidian notes, the browser's own menu and the agents running on the machine.

built for aside – a chromium browser with an agent in the sidebar. runs on any chromium 114+, manifest v3. every surface is drawn in the sidebar's own look.

01 · {palette}runs on this page · try: aim · mini · > · 19*3

type, don't hunt

with fifty tabs open, scanning a sidebar is slower than typing three letters.

the shape is raycast's: a row is icon, title, subtitle and its type on the right; the typed words are bold inside the row; the footer names what ↵ will do; ⌘K opens the actions for the row – switch, pin, bookmark ⇄ tab, close, copy url. esc clears the query first and closes only when it is empty.

an empty query shows the tabs you were in last, current one at the bottom. a page open twice carries ×2. history collapses by normalised url. ranking follows what you actually pick – frequency with a two-week decay. paste an address and it offers to open it plainly, in a named block, or pinned. arithmetic answers.

02 · {keep a page}a pin is a bookmark plus a tab

park, don't pile

aside's sidebar shows the bookmarks bar above the tabs. ⌘D writes the page as the last row of that bar, closes the tab and returns you to the page you came from. the row stays: one click opens the page again, and while it is open the sidebar folds the tab into that row – live, asleep with 💤 when discarded. that is arc's pinned tab, built from a bookmark and a tab.

⌘D on an open page that already sits in the bar removes the bookmark; the tab stays. the last tab of a window is never closed. settings card 02 can keep the tab open instead – it then leaves its block and moves to the first row, and the sidebar folds it in.

03 · {tidy up}one sweep, watch it move

tidy up

⌥⌘T is four operations in one gesture, in the order that survives: duplicates and empty tabs closed, groups flattened, loose tabs on top by recency, blocks rebuilt from three tabs or more. flattening comes before grouping – a grouped tab refuses to cross its group boundary.

a duplicate is the same address through http, www, a trailing slash and tracking params – and also the same site under the same title: four «aim visual» tabs with four query strings are one page to the eye. of the copies the one you used last stays. before anything closes, ⇧↵ on the clean duplicates row in the palette shows every candidate with its reason and the copy that stays; ⌘⌫ there closes one at a time.

04 · {keys}rebindable right here

take the key back

shortcuts belong to the person, not to the vendor.

an extension is normally allowed four shortcuts, re-bindable only on the browser's own settings page. this one listens on the page in the capture phase – before the browser applies its accelerator – so any combination the page can see becomes yours. bindings are stored by physical key code, so a non-latin keyboard layout doesn't quietly break them. click a row on the right and press a combination – the recorder is the same one that lives in the extension.

05 · {desk}notes and agents, from the palette

notes and agents

a browser extension cannot read a file or start a process. a small local server does it on its behalf: it keeps a filename index of every vault with the time of the last edit, reads obsidian's own «recent files», and opens a note through obsidian://. an empty query lists the notes modified last; the notes scope starts with a «today» section. type > and the same list shows the terminals running in orca – ↵ switches to one; > followed by a prompt starts a new claude in a folder you configured.

it listens on 127.0.0.1 only and answers only to a header this extension sends – a web page cannot add it without a cors preflight the bridge refuses. it opens only files inside a configured vault and starts an agent only in a configured folder. and from anywhere: a raycast script command or ⌥⌘K in hammerspoon opens the bridge's signal page in aside, and the extension turns that tab into the palette on the page you came from – or on a grey field where no page exists.

07 · {gestures}what each key moves
⇧⌘Kpalette

a layer over the page: no title bar, the page darkens behind it. where no page exists it opens as a window. ⇥ switches scope, esc clears then closes.

⌘Kactions

inside the palette: the actions of the selected row. switch · pin · bookmark ⇄ tab · close · copy url for a tab; open · pinned · in a block · copy for anything with an address. the printed keys work without opening it: ⇧↵ ⌘⌫ ⌘B ⌘C.

⌘Dbookmark ⇄ tab

the page joins the bookmarks bar as its last row, the tab closes, focus returns to the page you came from; the bar row opens it again. on an open page already in the bar: the bookmark goes, the tab stays.

⇧⌘Dpin

the squares on top of the sidebar. unpinning returns the page to the first row of the tabs and keeps it selected.

⌥⌘Dclean duplicates

by address or by host + title, plus empty tabs; the copy you used last stays. ⇧↵ on the row in the palette shows what would close before anything does.

⌥⌘Ttidy up

clean, flatten, order, rebuild blocks – reported once, not four times.

⌥⌘Kfrom anywhere

a system key (raycast script, hammerspoon) opens the bridge's signal page in aside; the extension turns it into the palette on the page you came from, or on a grey field where no page exists. the signal tab never stays.

⌃⇧Spanel

the last rows of the bookmarks bar, pinned tabs, the rest by blocks, commands – one list of commands feeds the panel, the palette and the popup.

08 · {limits}the ceiling, written down

what it will not do

the browser's own sidebar is native chrome – an extension cannot repaint or restyle it, and the theme colour leaves it alone. what this draws is themable instead, and by default it borrows the sidebar's own values: palette, popup, settings, panel. no extension can take ⌘T ⌘W ⌘N ⌘Q, on any browser, including the ones that advertise custom shortcuts. the browser's own ✦ tidy is part of that ceiling: no menu command, no url scheme, zero elements for accessibility – so this ships its own sweep. the bridge does nothing until you install it; without it the palette has no notes and > points you to the settings card.

the layer above extensions: ⌘T, ⌘W, ⌘N, ⌘Q belong to the system and no extension reaches them – the browser consumes them before a page exists. those keys are menu commands, and macOS re-binds any menu command per application. the repo ships that as a script, so the browser's own bookmark dialog stops sitting on ⌘D:

$ scripts/native-shortcuts.sh
  Bookmark This Tab…         → ⌃⌘B    frees ⌘D
  Bookmark All Tabs…         → ⌃⇧⌘B   frees ⇧⌘D
  Always Show Bookmarks Bar  → ⌥⇧⌘B   frees ⇧⌘B

menus build their key equivalents at launch, so it bites after the browser restarts. --reset puts the stock keys back.

09 · {install}two minutes · everything stays on the machine

install in two minutes

chrome://extensions → developer mode → load unpacked → pick the folder. the extension talks to the browser's own tab, history and bookmark apis, and – if you install the bridge – to a server on 127.0.0.1 that only answers to it.
