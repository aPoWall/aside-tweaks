the keys your browser kept for itself

fifty tabs, a bookmark dialog nobody asked for, new tabs landing at the top of the list. aside tweaks takes the keyboard back, moves a kept page to the top of the bar instead of copying it, and puts one palette over tabs, history and bookmarks.

type, don't hunt

with fifty tabs open, scanning a sidebar is slower than typing three letters. the palette searches open tabs, browser history and bookmarks at once, and tab narrows the scope.

02 · keys

a keymap that outranks the browser

an extension is normally allowed four shortcuts, re-bindable only on the browser's own settings page. this one listens on the page in the capture phase — before the browser applies its accelerator — so any combination the page can see becomes yours. bindings are stored by physical key code, so a non-latin layout doesn't quietly break them.

⌘Dbookmark upthe page becomes the first row of the bookmarks bar and the tab closes — it moves rather than existing twice
⇧⌘Dpinthe squares on top of the sidebar, the browser's own pin, on a key of its own
⌥⌘Ttidy upone sweep: duplicates and empty tabs closed, the rest grouped by your blocks, order aligned
⌘Kpalettecentred on the window, dims the page behind it
⌃⇧Spanelbookmarks bar top, pinned tabs, the rest by blocks, commands

the layer above extensions

⌘T, ⌘W, ⌘N, ⌘Q belong to the system and no extension reaches them — the browser consumes them before a page exists. those keys are menu commands, and macOS re-binds any menu command per application. the repo ships that as a script, so the browser's own bookmark dialog stops sitting on ⌘D:

$ scripts/native-shortcuts.sh
  Bookmark This Tab…         → ⌃⌘B    frees ⌘D
  Bookmark All Tabs…         → ⌃⇧⌘B   frees ⇧⌘D
  Always Show Bookmarks Bar  → ⌥⇧⌘B   frees ⇧⌘B

menus build their key equivalents at launch, so it bites after the browser restarts. --reset puts the stock keys back.

03 · install

two minutes, no store

$ git clone https://github.com/aPoWall/aside-tweaks.git

chrome://extensions → developer mode → load unpacked → pick the folder. chromium 114+, manifest v3. everything stays on the machine: no account, no server, no telemetry — the extension talks to the browser's own tab, history and bookmark apis and to nothing else.

get it on github ↗ read the docs ↗

what it will not do

the browser's own sidebar is native chrome — an extension cannot repaint or restyle it, and the theme colour leaves it alone. what this draws is themable instead: palette, popup, settings, panel. and no extension can take ⌘T ⌘W ⌘N ⌘Q, on any browser, including the ones that advertise custom shortcuts. the honest ceiling is written down rather than hidden.
