01keys
held by the browser itself
these live one level above the page: the browser fires them even where a page cannot listen — on chrome://, on a new tab, inside Aside's own interface. an extension may suggest them but never rebind them, so a key that still fires the old action is set here, not above. change or clear them on chrome://extensions/shortcuts.
⚠ ⌘T ⌘W ⌘N ⌘Q ⌘M ⇧⌘W stay with the system — the browser takes them before the page. on chrome:// pages, the new tab and inside Aside's own interface there is no page at all: only native shortcuts work there.

02pin vs bookmark
⌘D — bookmark ⇄ tab. the page lands as the last row of the bookmarks bar and the tab stays open and loaded. press it again on the same page: the bookmark goes away and the tab returns to the very top of the list.
⇧⌘D — pin. the squares on top of the sidebar, the browser's own pin on a key of its own.
03tabs
hold position 2500 ms
Aside moves a fresh tab after it is created, so the guard keeps putting it back until it stops drifting. raise it if new tabs still jump to the top.
04cleanup
the manual command also collapses empty new tabs — one per window stays. of two copies the one you used last is kept; http, www and a trailing slash do not make a different page.
tidy up · blocks from 3 tabs
tidy up gathers a block only from this many tabs of one rule or site; smaller sets stay loose on top, ordered by where you were last. pages that sit in the bookmarks bar stay out of blocks, so the sidebar can fold them into their row.
05blocks
a block is a name plus substrings. blocks drive tab grouping, the palette's «open in block» and the sections of the tweaks panel. anything unmatched falls back to its root domain.
06appearance
Aside's own sidebar is native browser chrome — an extension cannot repaint it, so the default look is lifted from it instead: the same grey field, a white pill on the selected row, the system font. paper is the older apowall instrument look — warm sheet, monospace lowercase. both drive every surface of ours: palette ⇧⌘K, popup, settings, tweaks panel.

08native shortcuts
keys the browser owns before any page exists — ⌘T, ⌘W, the bookmark dialog — are menu commands. no extension reaches them, but macOS re-binds any menu command per app, which is exactly what System Settings → Keyboard → Keyboard Shortcuts → App Shortcuts does by hand.
Bookmark This Tab…⌃⌘Bfrees ⌘D
Bookmark All Tabs…⌃⇧⌘Bfrees ⇧⌘D
Always Show Bookmarks Bar⌥⇧⌘Bfrees ⇧⌘B
already written to ~/Library/Preferences/at.studio.AsideBrowser.plist. menus build their key equivalents at launch, so this bites only after Aside is quit and reopened — until then the menu still shows the old keys. the App Shortcuts list also reads that file, so «Aside» shows up there once System Settings is reopened. modifiers in the syntax: @ ⌘ · ^ ⌃ · ~ ⌥ · $ ⇧. the repo ships scripts/native-shortcuts.sh — run it to apply the table, --reset to undo.
07blocks by meaning
a site is a weak signal: fifteen tabs on one github.com say nothing about what you are doing. this hands the titles and hosts of the open tabs to a model through OpenRouter and asks it for working blocks. page contents, cookies and full addresses are never sent. the answer arrives as a proposal in a small window — nothing is regrouped until you press apply. ⚠ titles are private text: a tab called «offer for <client>» leaves your machine as that sentence. the key lives in local storage only and never syncs to other machines. off until you put a key in.

09desk bridge
two things a browser extension cannot reach on its own live behind a tiny local server: recent notes from Obsidian (the vault's own «recent files» list, plus a filename search) and agents — live Orca terminals to switch to, and a new claude started in a working folder from > prompt in the palette. it listens on 127.0.0.1 only and answers only to this extension; nothing runs until you install it. install: bridge/install.sh, config in ~/.config/aside-tweaks/desk.json.

order
how many recent notes an empty query shows and in which order; the notes scope adds a «today» section with everything modified since midnight; a typed query always searches the vault by file name. from anywhere. a global key cannot reach an extension, but it can open a page: the bridge serves /aside-tweaks/palette, and the extension turns that tab into the palette on the page you came from (or on a grey field where no page exists). bind bridge/raycast/aside-palette.sh in Raycast — with an argument the palette opens with the query typed — or paste bridge/hammerspoon.lua for ⌥⌘K.
