01keys
⚠ ⌘T ⌘W ⌘N ⌘Q ⌘M ⇧⌘W stay with the system — the browser takes them before the page. on chrome:// pages, the new tab and inside Aside's own interface there is no page at all: only native shortcuts work there.
02pin vs bookmark
pin moves the tab into the squares on top of the sidebar and keeps it there — that is the Arc behaviour, bound to ⌘D by default.
bookmark puts the page into the bookmarks bar, no dialog, second call removes it. separate action, no key by default.

05blocks

07native shortcuts
keys the browser owns before any page exists — ⌘T, ⌘W, the bookmark dialog — are menu commands. no extension reaches them, but macOS re-binds any menu command per app, which is exactly what System Settings → Keyboard → Keyboard Shortcuts → App Shortcuts does by hand.
Bookmark This Tab…⌃⌘Bfrees ⌘D
Bookmark All Tabs…⌃⇧⌘Bfrees ⇧⌘D
Always Show Bookmarks Bar⌥⇧⌘Bfrees ⇧⌘B
already written to ~/Library/Preferences/at.studio.AsideBrowser.plist. menus build their key equivalents at launch, so this bites only after Aside is quit and reopened — until then the menu still shows the old keys. the App Shortcuts list also reads that file, so «Aside» shows up there once System Settings is reopened. modifiers in the syntax: @ ⌘ · ^ ⌃ · ~ ⌥ · $ ⇧. the repo ships scripts/native-shortcuts.sh — run it to apply the table, --reset to undo.
